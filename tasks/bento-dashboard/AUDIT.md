# UX/UI аудит и bento-редизайн рабочего стола (`#dashboard`)

Дата: 2026-09-28 · Канон: `docs/10-DESIGN/DESIGN-SYSTEM.md` §5.2d
Артефакты доказательства: `after-desktop.png`, `after-mobile.png`, `after-report.json`
(`node tasks/bento-dashboard/shot.js` при поднятом `python -m http.server 4173` из `products/website/apps/researchlab`).

## Что было не так (аудит)

1. **Раскладка без системы.** `.dw-grid` = `repeat(auto-fit, minmax(320px, 1fr))` давал одинаковые
   колонки независимо от содержания, а широкие блоки выходили из сетки костылём `.dw-widget-wide`.
   Канон §5.2a–§5.2c требует явных пропорций ячеек.
2. **Сводка стояла над сеткой** отдельным блоком со своим заголовком и датой — рабочий стол
   не читался как один bento.
3. **Два владельца стилей.** `redesign.css` (подключён позже, строка 70 против строки 42)
   переопределял карточки: радиус `md` вместо `-8`, `transform: none` поверх живого hover,
   `background: #ffffff` в белой теме. Дрейф гарантирован и уже случился.
4. **Мёртвый hover.** `book-card:hover { transform: translateY(-2px) }` не отрисовывался никогда —
   его гасил `redesign.css`; тень в пергаментной теме (`theme-parchment.css`) противоречила §0.2.
5. **Латентный баг вёрстки.** У дорожки полноты (`.dw-completeness-track/fill`) не было CSS вовсе:
   inline-спаны игнорируют `width/height`, полосы не рисовались.
6. **Четыре разных шапки** у восьми блоков (`h3` с линией, `.dw-widget-heading h3`, `h2` + кикер,
   заголовок без линии) вместо одной шапки §4.1.
7. **Шум в сводке:** «срез данных» повторялся под четырьмя показателями из пяти, при этом дата
   среза стояла в заголовке; у «Движения исследований» подпись-абзац ломала ритм (мера прозы
   `.lab-content .module p` = 20px снизу).
8. **Литералы вместо токенов:** `#b8860b`, `#7a6b9e`, `10/11/12/13/15/22/28px`, `width: 116px`,
   `44px`, `height: 5/8px`, `padding: 10px 12px` — вне лестниц §1.2/§1.3.
9. **Контраст:** hover ссылок давал `--accent-gold` текстом (3.1:1 на светлой подложке) — ниже AA §1.1;
   разделители сводки на `15%/70%` высоты ломались при рефлоу сетки на 2–3 колонки.
10. **Скролл/плотность:** страница 2029px на desktop 1280; лента на 390px схлопывалась в пустую полосу
    (процентный `flex-basis` внутри трека `width: max-content`).

## Что сделано

- Один bento: `.dw-bento` (12 колонок, gap `--space-3`), восемь ячеек `.dw-cell` с шапкой §4.1
  (номер главы, капительный заголовок, мета справа). Пропорции: сводка и лента — `1 / -1`,
  пары 8+4 и дважды 5+7, сумма каждой пары ровно 12 — пустых колонок нет.
- Мета переехала в шапку: дата среза, «8 событий», «29 книг», «8 из 21», «5 разборов»,
  «205 материалов», «14% · средняя полнота». Нейтральный срез в сводке не печатается.
- Списки и бары — строки-hairline (§4.8/§4.12) вместо плашек; все дорожки — 4px; подписи баров
  и счётчики на flex-долях.
- Единственный владелец стилей: дубли удалены из `redesign.css` и `theme-parchment.css`,
  регрессия закрыта тестом `testSingleStylesheetOwner`.
- Текст-ссылки — `--gold-text`; плоский UI (0 теней), радиусы только `--radius-*`.
