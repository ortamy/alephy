# Модули интерфейса

Лаборатория — статическое Vanilla JS SPA. Адрес модуля — hash: `#architecture`, `#documentation`. Перезагрузки страницы нет.

## Как устроен вход

Единственный список маршрутов — `js/module-registry.js`. Роутер и `page-controller` читают его оттуда. Сайдбар в `index.html` обязан совпадать с полем `nav` реестра: расхождение ловит `tools/design-baseline/registry-check.mjs`.

Новый модуль появляется так:

1. Запись в реестре (`kind: 'panel'` или `'markdown'`).
2. Пункт сайдбара, если модуль должен быть виден.
3. `case` в `js/page-controller.js`.
4. Скрипт и стили в `index.html`.

Модуль без `nav` открывается только по прямому адресу, из палитры поиска или deep-link. Это штатный способ скрыть пункт, а не ошибка.

## Разделы сайдбара

- **Верх:** манифест, рабочий стол, мастерская, палео-клуб.
- **Данные:** словари, методология, карта языков, состояния, таймлайн.
- **Инструменты:** палео-конструктор, палео-клавиатура.
- **AI:** агенты, пайплайны, сервер, нейрочат.
- **Система:** настройки, дизайн-система, архитектура, документация.

## Система

| Маршрут | Зачем |
|---|---|
| `#admin-settings` | Тема, язык, режим разработчика |
| `#design-system` | Живые образцы канона |
| `#architecture` | Слои, стек, поток, гейты |
| `#documentation` | Эти гайды |

Панель разработчика — не пункт сайдбара, а оверлей поверх любого модуля. Как её включить — в гайде [Панель разработчика](#documentation/dev-panel).
