## ВВЕДЕНИЕ

Приёмы — это конкретные техники, которыми система искажает эмет. Механизмы (в отдельном файле) — глобальные стратегии. Методы (в отдельном файле) — как разоблачать. Приёмы — инструменты. Знать приёмы — значит видеть руку системы в каждом искажении.

Ниже — полный каталог приёмов, сгруппированный по сферам. Каждый приём содержит суть, палео-сборку (где применимо), способ распознавания, пример, тип искажения, Хук Свива и Керувы.

## ЯЗЫКОВЫЕ ПРИЁМЫ

### Транслитерация вместо перевода

**Суть:** Система не переводит — она импортирует. Непереведённое слово остаётся непонятным, а значит — управляемым.

**Палео-сборка:** 𐤋 (направление) + 𐤔 (огонь) + 𐤅 (связка) + 𐤍 (движение жизни) = направление, которое огонь связкой ведёт к жизни. Язык — это структура мышления. Когда система импортирует слово, она импортирует и чужую структуру.

**Как распознать:** Если слово звучит как греческое или латинское, но не переведено — это приём. «Диаболос» → «дьявол». «Экклесия» → «церковь».

**Пример:** `διάβολος` → «дьявол» (вместо «клеветник»). Система не переводит — импортирует. Слово остаётся непонятным, а значит — управляемым.

**Тип искажения:** Подмена категории, Кастрация смысла.

**Хук Свива:** непереведённое слово создаёт Мицраим; перевод создаёт Шамаим.

**Керувы:** Переводить, а не транслитерировать.

### Замена конкретного абстрактным

**Суть:** Иврит мыслит конкретно. Система заменяет конкретное абстракциями.

**Палео-сборка для 𐤍𐤐𐤔:** 𐤍 (движение жизни) + 𐤐 (рот, дыхание) + 𐤔 (огонь) = жизнь, дышащая через рот, согретая огнём. Образ: дышащее существо. Не субстанция, а существо, которое дышит.

**Как распознать:** Если понятие можно «почувствовать» в иврите, но в переводе оно становится «идеей» — это приём.

**Пример:** `𐤍𐤐𐤔` → «душа» (дышащее существо → абстрактная субстанция); `𐤓𐤅𐤇` → «дух» (дыхание, ветер → бесплотная сущность); `𐤀𐤌𐤅𐤍𐤄` → «вера» (верность в делах → внутреннее состояние).

**Тип искажения:** Абстракция, Сужение смысла, Психологизация.

**Хук Свива:** абстракция создаёт Тоху; конкретика создаёт Эрец.

**Керувы:** Возвращать конкретный образ.

### Замена действия состоянием

**Суть:** Глагол требует поступка, существительное — только признания. Система заменяет глагол на существительное.

**Палео-сборка для 𐤀𐤌𐤅𐤍𐤄:** 𐤀 (сила) + 𐤌 (поток) + 𐤅 (связка) + 𐤍 (движение жизни) + 𐤄 (проявление) = сила, текущая потоком, связанная с жизнью, в проявлении. Образ: верность — это активное течение силы.

**Как распознать:** Если понятие можно «иметь» без действия — это приём. «У меня есть вера» — значит, я ничего не делаю.

**Пример:** `𐤀𐤌𐤅𐤍𐤄` → «вера» (верность в делах → внутреннее чувство); `𐤕𐤔𐤅𐤁𐤄` → «покаяние» (возвращение → чувство вины); `𐤉𐤔𐤅𐤏𐤄` → «спасение» (избавление из беды → статус).

**Тип искажения:** Сдвиг от действия к эмоции, Психологизация.

**Хук Свива:** состояние создаёт Хошех; глагол создаёт Мидбар.

**Керувы:** Заменять существительные глаголами.

### Замена функции титулом

**Суть:** Функция скрыта за титулом. Контроль становится незаметным.

**Палео-сборка для 𐤊𐤄𐤍:** 𐤊 (удержание) + 𐤄 (проявление) + 𐤍 (движение жизни) = удержание, которое проявляет движение жизни. Образ: помощник, который открывает доступ к жизни.

**Как распознать:** Если слово звучит как звание, а не как действие — это приём.

**Пример:** `ἐπίσκοπος` → «епископ» (надзиратель → священный сан); `𐤌𐤋𐤀𐤊` → «ангел» (вестник → вид небесного существа).

**Тип искажения:** Подмена категории.

**Хук Свива:** титул создаёт Мицраим; функция создаёт Шамаим.

**Керувы:** Возвращать функцию.

### Замена описания именем

**Суть:** Роль становится личностью. Функция становится существом.

**Как распознать:** Если слово можно «назвать» как имя, но нельзя «описать» как действие — это приём.

**Пример:** `διάβολος` → «Дьявол» (клеветник → существо с именем). `𐤔𐤈𐤍` → «Сатан» (противник → имя собственное).

**Тип искажения:** Подмена категории, Дуализация.

**Хук Свива:** имя-ярлык создаёт Мицраим; описание создаёт Ракиа.

**Керувы:** Возвращать описание.

### Смешение нескольких слов в одно

**Суть:** Три разных понятия слиты в одно. Различия стёрты.

**Палео-сборка для 𐤀𐤄𐤁𐤄:** 𐤀 (сила) + 𐤄 (проявление) + 𐤁 (вместилище) + 𐤄 (проявление) = сила, которая проявляется во вместилище. Образ: любовь как действие, а не чувство.

**Как распознать:** Если в иврите есть несколько слов для одного «чувства», а в переводе — одно — это приём.

**Пример:** `𐤀𐤄𐤁𐤄`, `𐤓𐤇𐤌`, `𐤇𐤎𐤃` → «любовь» или «милость». Три разных понятия слиты в одно.

**Тип искажения:** Сужение смысла, Абстракция.

**Хук Свива:** смешение создаёт Хошех; различение создаёт Ракиа.

**Керувы:** Различать.

### Разрыв корневых связей

**Суть:** В иврите слова связаны через корень. Перевод разрывает эти связи.

**Палео-сборка для 𐤑·𐤃·𐤒:** 𐤑 (захват) + 𐤃 (проход) + 𐤒 (пронзание) = захват, который проход пронзает. Образ: справедливость как действие, а не состояние.

**Как распознать:** Если слова, которые в иврите имеют общий корень, в переводе выглядят как неродственные — это приём.

**Пример:** `𐤑𐤃𐤉𐤒` (праведник), `𐤑𐤃𐤒𐤄` (справедливость), `𐤄𐤑𐤃𐤉𐤒` (оправдал) → три неродственных слова в русском.

**Тип искажения:** Абстракция, Сужение смысла.

**Хук Свива:** разрыв создаёт Хошех; связь создаёт Эрец.

**Керувы:** Восстанавливать корневые связи.

**Пример:** `𐤀𐤅𐤓` (свет) и `𐤏𐤅𐤓` (кожа) — омофоны. Перевод теряет связь между светом и кожей Адама.

### Подмена языка творения на язык описания

**Суть:** Язык действия стал языком философии.

**Палео-сборка для 𐤃𐤁𐤓:** 𐤃 (проход) + 𐤁 (вместилище) + 𐤓 (вершина) = проход, который открывает вместилище к вершине. Образ: слово как действие.

**Как распознать:** Если слово стало «мыслью», а не «действием» — это приём.

**Пример:** `𐤃𐤁𐤓` (слово-дело) → `λόγος` (идея). Язык действия стал языком философии.

**Тип искажения:** Абстракция, Подмена категории.

### Подмена исцеления на лечение

**Суть:** Целостность → устранение симптомов.
