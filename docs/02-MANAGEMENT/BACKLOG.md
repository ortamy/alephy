## ⏸️ ОТЛОЖЕНО (разбор внешних репозиториев, 2026-10-02)

Источники: [impeccable](https://github.com/pbakaus/impeccable),
[nanobot](https://github.com/HKUDS/nanobot),
[hindsight](https://github.com/vectorize-io/hindsight),
[laya](https://github.com/NandhaKishorM/laya),
[kev](https://github.com/jaredpalmer/kev),
[mitosis](https://github.com/BuilderIO/mitosis).

Полезного из шести репозиториев оказалось два пункта, а не одиннадцать:
остальное — инфраструктура для ИИ-продуктов, тогда как у нас исследовательская
лаборатория со статическим SPA и агентами, половина из которых — заглушки.
Решение: отложить всё до появления предпосылок.

### Стоит сделать, когда дойдём до агентов

- [ ] **Атрибуция решения** — агент возвращает
      `{verdict, evidence: [{file, line, selector, rule}]}`, UI подсвечивает строку.
      Причина в методологии, а не в удобстве: §11 требует отличать факт от гипотезы,
      а вердист без ссылки на место неотличим от выдумки, просто уверенно оформленной.
      Приём взят из `predict_long` (kev/laya), который возвращает `token_start/token_end`.
      Технически бесплатно: аудит канона эти координаты уже знает.
- [ ] **Дельты прогонов аудита** — паспорт не перезаписывает прошлый запуск, а
      показывает «было 18 → стало 9». Один прогон говорит о состоянии, два — о динамике.
- [ ] **Канон как машиночитаемые данные** — правило §4.1a сейчас существует прозой,
      агент парсит её регулярками, человек проверяет глазами: три копии одного
      правила, и они разошлись (отсюда баг с чёркой под заголовком ячейки).
      Дёшево и без четвёртой копии: один файл правил, проза в DESIGN-SYSTEM ссылается
      на него, а не дублирует. Вариант «MD + JSON рядом» — отклонить, он добавит
      новый источник расхождения.
- [ ] **`canon-waive`** — inline-маркер осознанного отступления от канона
      (`/* canon-waive: правило — причина */`). Сейчас отступление либо невидимо,
      либо живёт в голове автора. Низкий приоритет: проблема есть, но не давит.
- [ ] **`tools/check-design.py`** — исполняемый ANTI-SLOP-CHECKLIST через
      Playwright по вычисленным стилям (не по исходнику CSS — так обходится каскад).
      Окупается, когда правил три независимых потребителя; сейчас их два.
      Риск — ложные срабатывания, после которых гейт начинают игнорировать;
      в блокирующий CI правило входит только после зелёного прогона на текущем коде.
      **Жёсткая зависимость:** начинать только после «Канон как данные».

### Когда клуб станет хранилищем, а не лентой

- [ ] **Память клуба** (`retain/recall/reflect`) — единственный пункт из отложенных
      с настоящей исследовательской ценностью: через год отвечаем «что мы уже
      установили про этот корень» вместо повторного вывода. Сначала накопить
      материал, потом переваривать.
- [ ] **Сканер секретов на входе в клуб** — 45 паттернов, redact или отказ.
      Дыра реальна (`check-commit.py` ловит токен только в закоммиченном файле),
      но закрывать её пока некуда: хранилища нет.
- [ ] **Банк памяти на агента-аудитора** — текущий прогон против прошлых,
      ложные срабатывания помнятся между запусками. Первый элемент состояния,
      живущий дольше прогона; требует правила хранения, иначе банк начнёт врать.
- [ ] **Планировщик регулярных аудитов** — автоматика, пишущая в клуб без
      человека. Основной эффект — шум. Не раньше, чем клуб перестанет быть заглушкой.

### Отклонено окончательно

- [ ] **Mitosis как зависимость** — нарушает §7 (Vanilla JS SPA, «не создавай
      React-компоненты»), §8 (бюджет бандла) и §9 (единственный агентный сервер).
      Идею берём в «Канон как данные», сам компилятор — нет.
- [ ] **Веса kev/laya как рантайм** — GPU/RAM, которых нет; §3 требует дешёвый
      стек, §14 — ADR. Берём приём (атрибуция), не модель.
- [ ] **WebUI из nanobot** — дублирование Research Lab.

> Отдельная оговорка: `kev` и `laya` ссылаются на архитектуру «Jev's Architecture
> Unmasked» и API TypeSafe `System One`, а их метрики точности — заявления авторов,
> не независимые бенчмарки. Если эти пункты когда-нибудь дойдут до реализации,
> проверять первоисточник, а не README.
