# Linear → ALEPHY: карта заимствований (2026-09-06)

Референс — интерфейс Linear (issue-трекер, linear.app). Берём **плотность и дисциплину**, не цветовую палитру: наша идентичность — «современный манускрипт» (пергамент + золото), она сохраняется.

## Принципы, которые переносим

1. **Плотность и тишина.** Сетка 4px, контролы 24–28px, whitespace между блоками, а не внутри контролов. Данные видны сразу, hero не съедает экран.
2. **Рамки вместо теней.** 1px border + смена фона при hover. `box-shadow` — только оверлеи (модалки, поповеры, тосты).
3. **Двухслойная типографика.** UI = гротеск (`--font-ui`, DM Sans 11–15px), контент = serif (Garamond). Заголовки различаются размером и весом, не цветом.
4. **Один акцент.** Золото (у Linear — индиго): ссылки, активные состояния, фокус. Статусы — отдельная семантика (зелёный/янтарный/красный), не декор.
5. **Строки, а не карточки.** Списки с hairline-разделителями; карточки — только витрины и дашборд.
6. **Мета-строка.** `автор · время · счётчик` — 12px muted, единый паттерн везде.
7. **Клавиатура и фокус.** Focus-ring всегда видим; хоткеи — уже есть (LabHotkeys), развивать.

## Что НЕ копируем

- Тёмно-серый монохром Linear — у нас палитра манускрипта (пергамент/white/dark/brown).
- Inter — у нас DM Sans (уже в preload, `--font-ui`).
- Операционный шум: текстовые пилюли-статусы в каждой строке — у наших данных другая природа (исследования, а не тикеты).

## Правило внедрения

Новый паттерн: переиспользуемый → общий слой (`css/redesign.css`), единичный → CSS модуля → запись в `DESIGN-SYSTEM.md` → smoke-тест. UI-текст всегда `--font-ui`; serif не трогаем в читалках (манифест, писания).
