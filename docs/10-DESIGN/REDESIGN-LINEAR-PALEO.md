## 1. ЦЕЛЬ И ПРИНЦИП

Направление: **«Linear-инструментальность + палео-тёплость»**.

От Linear берём не «картинку», а инженерную дисциплину интерфейса:
- плотность и компактность элементов;
- тонкие рамки вместо теней и «плавающих» карточек;
- сдержанный единственный акцент;
- клавиатура и команды как первый способ управления;
- тёмная рабочая тема как полноценная среда.

Сохраняем палео-идентичность:
- палитра — тёплые нейтрали (пергамент/беж/шоколад/чёрный) вместо холодных серых;
- золото — единственный акцент;
- EB Garamond — смысловые заголовки, DM Sans — интерфейс;
- палео-глифы — «иконки смысла».

Главное отличие от «скопировать Linear»: у Linear нейтрали холодные и безликие. У нас нейтрали **тёплые** — те же приёмы плотности, но пергамент, беж и шоколад вместо серого. Это и есть дифференциатор.

## 2. КОМПАКТНОСТЬ И ПЛОТНОСТЬ (как у Linear)

### 2.1. Базовая сетка

- Единица — **4px**. Все отступы кратны 4.
- Плотный режим Research Lab — отступы кратны 4, обычный — кратен 4 с шагом ×1.5 для «воздуха» между секциями.
- Высота строк управления в плотном режиме: **кнопки 24–28px, инпуты 26–30px** (у Linear маленькие контролы — это его узнаваемая черта).
- Радиусы: контролы **4–6px**, карточки/панели **6–8px**, модалы **10–12px**. Никаких «пилюль» у функциональных кнопок (пилюля допустима только у бейджей-статусов).

### 2.2. Типографика интерфейса

- Интерфейсный текст: **13px**, вторичный **12px**, метки/хинты **11px**.
- Заголовки модулей (hero): крупный Garamond остаётся, но сам hero становится ниже — компактный «баннер», а не плакат.
- Межстрочные: 1.4–1.5 у текста, 1.2 у заголовков.
- Кнопки: текст **12–13px**, без капса для вторичных; капс — только «кикер»-надписи золотом.

### 2.3. Компоненты — целевые размеры

Список целевых характеристик (плотный режим):

- Кнопка первичная/вторичная: высота 26px, горизонтальный паддинг 10–12px, радиус 6px, иконка 14–16px.
- Инпут/селект: высота 28px, паддинг 4–6px по вертикали, 8px по горизонтали, радиус 6px.
- Текстареа: паддинг 8px, монотонный таб-фокус.
- Селект-категорий и фильтры: высота 26px, компактный вид.
- Статус-бейдж/пилюля: высота 18–20px, паддинг 2px 8px, радиус 999px, текст 11px с letter-spacing 0.02em, слева — цветная точка-индикатор (как у Linear).
- Таблицы/списки строк: строка **32px**, ячейки паддинг 4px 8px, разделители — только горизонтальные 1px.
- Чекбокс/радио: 14–16px.
- Табы: высота 28px, активный — подчёркивание/подложка 1px рамки.
- Сайдбар-пункт: высота 28px, иконка 16px, активный — золотая полоса слева (2px) + приглушённая подложка.
- Тултип/popover: тень + рамка, паддинг 6px 10px, текст 12px.

### 2.4. Плотность по умолчанию

- Плотный режим — **по умолчанию** для Research Lab (настройка в `user-preferences.js` остаётся: «Компактный / Комфортный»).
- Лендинг остаётся «воздушным» (маркетинговая страница), но элементы форм (waitlist) приводятся к тем же компактным контролам.

## 3. ПАЛИТРА И ТОКЕНЫ

### 3.1. Принцип

Три–четыре слоя поверхности + один акцент. Границы между слоями — тонкие рамки `1px`, а не тени. Тени — только у плавающих слоёв (модал, popover, палитра команд).

### 3.2. Светлые темы

- Фон приложения (`--paper`): пергамент `#f5f0e6` для `parchment`, `#ffffff` для `white`.
- Поверхность (карточка/панель) (`--surface`): светлее фона на 2–4%.
- Поднятая поверхность (hover/popover) (`--surface-2`): ещё на шаг светлее/контрастнее.
- Рамки (`--line`): `rgba(45,31,20,0.10–0.16)`.
- Текст: `--chocolate` `#2D1F14`, вторичный `--chocolate-soft`/`--muted`.
- Акцент: `--gold` `#C89B3C` (hover — `--gold-deep`).
- Статусы: эмет-зелёный/терракота приглушённые (не сигнальные).

### 3.3. Тёмные темы

- `dark` (шоколад): фон `#2D1F14`, поверхность `#3b2a1c`, поднятая `#493323`.
- Новая `black`: фон почти чёрный тёплый `#1a120c`, поверхность `#241a12`, поднятая `#2e2116` — как «Linear dark», но тёплый.
- Рамки на тёмном: `rgba(245,240,230,0.10–0.18)`.
- Текст: `#F5F0E6`, вторичный `#c9b89d`.
- Золото на тёмном: `#C89B3C`, не бледное.
- Контраст текста — WCAG AA (минимум 4.5:1 для основного, 3:1 для крупного).

### 3.4. Новые токены (вводятся в `lab.css` и `theme-*.css`)

Список токенов-слоёв для единообразного редизайна:

- `--surface`, `--surface-2`, `--surface-hover`;
- `--control-h` (28px), `--control-h-sm` (24px);
- `--radius-s` (4px), `--radius` (6px), `--radius-lg` (10px);
- `--line-strong`, `--line-subtle`;
- `--shadow-pop` (только плавающие слои);
- `--font-ui-size` (13px), `--font-ui-size-sm` (12px), `--font-ui-size-xs` (11px);
- `--space-1` (4px) … `--space-8` (32px);
- `--status-ok`, `--status-warn`, `--status-danger` (приглушённые).

Старые токены (`--shadow-soft` на карточках и т.п.) помечаются устаревшими и вычищаются по модулям.

## 5. ПОВЕРХНОСТИ МОДУЛЕЙ (порядок приведения)

1. Токены и хром (сайдбар, шапка, поиск, палитра команд).
2. Dashboard («рабочий стол») — эталон компактности: виджеты-строки, а не карточки с тенями.
3. Словари/корневой словарь: списки-строки, фильтры-селекты 26px, статус-бейджи (факт/интерпретация/гипотеза).
4. Learn/тренажёр: карточки с рамкой, прогресс тонкой полосой.
5. Workbench/пайплайны: строки запусков со статус-пилюлями (running/done/error/cancelled) и точкой-индикатором.
6. Клуб, методология, остальные модули — по этому же шаблону.
7. Лендинг: сохранить крупный hero, но формы и кнопки привести к компактным контролам.

Каждый модуль: карточки → `--surface` + рамка; кнопки → компактные; вторичный текст → 12px; тени → убрать.

## 6. КЛАВИАТУРА И КОМАНДЫ (как у Linear)

- Cmd/Ctrl+K — палитра команд (есть каркас).
- `/` — поиск (есть на лендинге; добавить в Lab).
- `g` затем `d`/`l`/`c`… — переходы по разделам (опционально, как Linear-роутинг).
- `Esc` — закрыть popover/палитру/модал.
- `?` — справка по хоткеям (есть `shortcuts.js` — проверить и обновить список).
- Стрелки в палитре/поиске — навигация, Enter — выбор.
