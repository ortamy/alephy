## 🔥 ВВЕДЕНИЕ

Науцизмы — научные термины, которые система превратила в магические заклинания. Их используют не для познания, а для подавления. «Наука доказала» звучит как «так говорит Яхве». Но наука — не бог. Это инструмент познания творения, а не Творец.

**Палео-образ науки:** 𐤌·𐤃·𐤏 — мада: знание, наука. 𐤌 (вода) + 𐤃 (дверь) + 𐤏 (глаз) = поток, который дверь направляет через глаз. Наука — это поток знания, а не источник.

**Палео-образ знания:** 𐤃·𐤏·𐤕 — даат: знание-близость. 𐤃 (дверь) + 𐤏 (глаз) + 𐤕 (знак) = дверь, через которую глаз видит знак. Знание — это близость, а не информация.

**Связанные документы:** `MANIFEST.md` (методология, карта пространств), `mechanisms.md` (Механизм 7 — Подмена палео-механики на греческую физику), `principles.md` (23 принципа разоблачения), `dictionary-exposures.md` (статья «Даат»).
