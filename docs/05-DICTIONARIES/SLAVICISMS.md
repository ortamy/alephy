## 🔥 ВВЕДЕНИЕ

Церковнославянизмы — это слова, созданные или переосмыслены в церковнославянском языке при переводе греческих текстов. Они не имеют корней ни в иврите, ни в греческом, ни в латыни — это искусственные конструкции, созданные для нужд системы.

**Палео-образ церковнославянского:** 𐤏·𐤁·𐤃 — авад: служить, работать. 𐤏 (глаз) + 𐤁 (дом) + 𐤃 (дверь) = глаз, который дом направляет через дверь. Церковнославянский — это служение через искажённый язык.

**Примечание о `roots.json`:** `roots.json` — это справочный словарь, который может содержать квадратное письмо для внешних ссылок. В палео-разборах мы используем только 𐤀–𐤕. Если в `roots.json` указано квадратное письмо, это не влияет на палео-механику, которая всегда записывается через 𐤀–𐤕.

**Связанные документы:** `religionisms.md` (словарь религионимов), `grecisms.md` (словарь грецизмов), `latinisms.md` (словарь латинизмов), `mechanisms.md` (Механизм 3 — Подмена многомерной истины плоским суррогатом), `principles.md` (23 принципа разоблачения).

### Как пользоваться словарём

1. **Найди слово** в списке (например, «заповедь»).
2. **Прочитай палео-ивритский оригинал** (например, 𐤌𐤑𐤅𐤄 — мицва).
3. **Изучи палео-сборку** (например, 𐤌 + 𐤑 + 𐤅 + 𐤄 = вода, крюк, крюк, окно).
4. **Пойми функцию** (например, связь).
5. **Примени Хук Свива** (например, «заповедь» → Мицраим; «связь» → Шамаим).
6. **Примени Керувы** (например, возвращать «связь» вместо «заповедь»).

**Пример использования:**

- **Вместо:** «Я исполняю заповедь» → **Сказать:** «Я укрепляю связь (мицва) с Яхве».
- **Вместо:** «Чистая душа» → **Сказать:** «Пригодное для присутствия дыхание (𐤈𐤄𐤅𐤓 𐤍𐤐𐤔)».

  - **Каппорет:** промах к смерти.
  - **Керувы:** возвращать «промах к смерти» вместо «хула на Духа».
- **Пример использования:**
  - **Вместо:** «Хула на Духа» → **Сказать:** «Промах к смерти (𐤇𐤈𐤀 𐤋𐤌𐤅𐤕)».


### 27. Чистый → Таhор (𐤈𐤄𐤅𐤓)

- **Ивритский оригинал:** 𐤈𐤄𐤅𐤓 (таhор) — пригодный для присутствия.
- **Палео-форма:** 𐤈𐤄𐤅𐤓 — 𐤈 (змея) + 𐤄 (окно) + 𐤅 (крюк) + 𐤓 (голова) = змея, которую окно направляет через крюк к голове.
- **Функция:** пригодный для присутствия.
- **Корень:** 𐤈·𐤄·𐤅·𐤓 — быть чистым.
- **`root_ref`:** `roots.json#tahor`
- **Уровень уверенности:** `факт` (корень зафиксирован).
- **Терминологическая проверка:** таhор — это пригодный, а не «чистый».
- **Хук Свива:** «Чистый» как моральный ярлык создаёт среду Мицраим (тесноту). Таhор как пригодный создаёт среду Шамаим (открытость).
- **Принцип Арона:**
  - **Арон:** `roots.json#tahor`, ТаНаХ.
  - **Каппорет:** пригодный как состояние.
  - **Керувы:** возвращать «пригодный» вместо «чистый».
- **Пример использования:**
  - **Вместо:** «Чистая душа» → **Сказать:** «Пригодное для присутствия (таhор) дыхание».
