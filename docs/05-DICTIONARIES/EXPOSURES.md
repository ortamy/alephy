## СТАТЬИ СЛОВАРЯ

### 1. АДАМА (ЗЕМЛЯ)

- **Слово в переводе:** Земля
- **Ивритский оригинал:** אֲדָמָה (Адама)
- **Палео-образы (справа налево):** א (сила/бык) + ד (дверь/проход) + מ (вода/поток) + ה (окно/откровение)
- **Палео-механика:** א (сила) направляется через ד (дверь) в מ (поток), который проходит через ה (откровение).
- **Визуальная сборка:** сила, открывающая дверь потоку, который течёт к откровению.
- **Функция:** материал, из которого слеплена форма.
- **Корень:** א.ד.מ — быть красным, глинистым.
- **`root_ref`:** `roots.json#adamah`
- **Живой образ:** глина, из которой гончар лепит сосуд.
- **Тип искажения:** Абстракция + Сужение смысла.
- **Механизм подмены:** Подмена палео-механики на греческую физику (Механизм 7).
- **Метод разоблачения:** Палео-механический разбор (Метод 1) + Конкретизация (Метод 4).
- **Карта утрат:** адама (глина) → γῆ (стихия) → «земля» (планета) → «почва» (абстрактный объект).
- **Уровень уверенности:** `факт` (корень зафиксирован, цепочка документирована).
- **Терминологическая проверка:** Адама — не «земля» как планета. Это глина. Возвращаем конкретный образ.
- **Хук Свива:** Адама создаёт среду Мицраим (тесноту), когда её называют «планетой» — человек перестаёт видеть материал, из которого он сделан.
- **Принцип Ковчега:** Арон (корень א.ד.м) → Каппорет (глина как материал) → Керувы (человек — из глины, а не из «земли» как абстракции).
- **Разбор:** Адама — это не «планета Земля» в космическом смысле. Это глина. Красная глина. Это материал, из которого сделан человек. Когда Яхве говорит «Адама», он говорит о конкретной земле под ногами, о материале, из которого ты слеплен. Греки превратили это в γῆ — «земля как планета», абстрактный объект в космосе.
- **Стихи:** Берешит 2:7 («прах от адама»), Берешит 3:19 («возвратишься в адама»).
- **Пример восстановления:** «Адам был взят из глины» вместо «Адам был взят из земли».
- **Оставшиеся варианты:** «почва», «красная глина».


### 2. АНГЕЛ

- **Слово в переводе:** Ангел
- **Ивритский оригинал:** מַלְאָךְ (малъах)
- **Палео-образы (справа налево):** מ (вода/поток) + ל (посох/направление) + א (сила/бык) + כ (ладонь/удержание)
- **Палео-механика:** מ (поток) направляется ל (посохом) через א (силу) и фиксируется כ (ладонью).
- **Визуальная сборка:** поток, направляемый силой через ладонь.
- **Функция:** вестник (тот, кто передаёт поручение).
- **Корень:** ל.א.כ — посылать, передавать.
- **`root_ref`:** `roots.json#malach`
- **Живой образ:** гонец, который бежит с письмом.
- **Тип искажения:** Подмена категории (функция → существо).
- **Механизм подмены:** Подмена живого отношения на мёртвую структуру (Механизм 4).
- **Метод разоблачения:** Функциональное опознание + Морфологическое вскрытие.
- **Карта утрат:** малъах (вестник) → ἄγγελος (посланник) → «ангел» (существо) → «крылатое создание» (мифология).
- **Уровень уверенности:** `факт` (корень и функция зафиксированы).
- **Терминологическая проверка:** малъах — это функция «вестник», а не вид существа.
- **Хук Свива:** «Ангел» как существо создаёт среду Хошех (сжатость) — ты не можешь стать вестником, потому что «ангелы» — это отдельная раса.
- **Принцип Ковчега:** Арон (корень ל.א.כ) → Каппорет (функция «вестник») → Керувы (вестником может быть человек, ветер, огонь).
- **Разбор:** малъах — не вид существа. Это функция «вестник». Исполнять может человек (Хагай 1:13 — пророк назван малъах), ветер (Теhилим 104:4 — ветры названы малъахав), огонь. Система превратила функцию в расу крылатых созданий. В иврите нет слова «ангел» как существа. Есть вестник как поручение.
- **Стихи:** Хагай 1:13 («малъах Яхве»), Теhилим 104:4 («ветры — малъахав»).
- **Пример восстановления:** «И сказал Хагай, вестник Яхве» вместо «Аггей, ангел Господень».
- **Оставшиеся варианты:** «посланник», «гонец».


### 3. БЛАГОДАТЬ

- **Слово в переводе:** Благодать
- **Ивритский оригинал:** חֵן (хэн)
- **Палео-образы (справа налево):** ח (ограда/отделение) + נ (жизнь/движение)
- **Палео-механика:** ח (ограда) отделяет נ (жизнь) — создаёт пространство для склонения.
- **Визуальная сборка:** ограда, отделяющая жизнь.
- **Функция:** расположение, благосклонность.
- **Корень:** ח.נ.נ — быть благосклонным, склоняться.
- **`root_ref`:** `roots.json#chen`
- **Живой образ:** человек, который склоняется к другому.
- **Тип искажения:** Психологизация + Абстракция.
- **Механизм подмены:** Подмена многомерной истины плоским суррогатом (Механизм 3).
- **Метод разоблачения:** Образное картирование + Этимологическая хирургия.
- **Карта утрат:** хэн (склонение) → χάρις (дар) → «благодать» (энергия) → «милость» (чувство).
- **Уровень уверенности:** `факт` (корень зафиксирован).
- **Терминологическая проверка:** хэн — это склонение, а не безличная сила.
- **Хук Свива:** «Благодать» как безличная сила создаёт среду Мицраим (тесноту) — ты должен её «получить», а не просто принять расположение.
- **Принцип Ковчега:** Арон (корень ח.נ.נ) → Каппорет (склонение как действие) → Керувы (Яхве склоняется к человеку).
- **Разбор:** хэн — не «благодать» как безличная сила. Это склонение. Яхве склоняется к человеку. Благосклонность. Расположение. Конкретное отношение, а не абстрактная субстанция. Система сделала из этого «энергию спасения», которую можно «получить».
- **Стихи:** Берешит 6:8 («Ноах нашёл хэн в глазах Яхве»).
- **Пример восстановления:** «Ноах нашёл расположение в глазах Яхве» вместо «обрёл благодать пред очами Господа».
- **Оставшиеся варианты:** «расположение», «благосклонность».


### 4. БЛАГОСЛОВЕНИЕ

- **Слово в переводе:** Благословение
- **Ивритский оригинал:** בְּרָכָה (браха)
- **Палео-образы (справа налево):** ב (дом/вместилище) + ר (голова/вершина) + כ (ладонь/удержание) + ה (окно/откровение)
- **Палео-механика:** ב (дом) направляется ר (головой) через כ (ладонь) к ה (откровению).
- **Визуальная сборка:** дом, который голова направляет через ладонь к откровению.
- **Функция:** наделение силой.
- **Корень:** ב.ר.כ — преклонять колено, наделять силой.
- **`root_ref`:** `roots.json#bracha`
- **Живой образ:** отец, который передаёт власть сыну.
- **Тип искажения:** Психологизация + Сдвиг от действия к эмоции.
- **Механизм подмены:** Подмена многомерной истины плоским суррогатом (Механизм 3).
- **Метод разоблачения:** Этимологическая хирургия + Морфологическое вскрытие.
- **Карта утрат:** браха (наделение силой) → εὐλογία (хорошее слово) → «благословение» (пожелание) → «благодарность» (чувство).
- **Уровень уверенности:** `факт` (корень зафиксирован).
- **Терминологическая проверка:** браха — это наделение силой, а не пожелание.
- **Хук Свива:** «Благословение» как пожелание создаёт среду Мицраим (тесноту) — ты ждёшь, что кто-то скажет «будь здоров». Браха как наделение силой создаёт среду Шамаим (открытость) — ты получаешь способность действовать.
- **Принцип Ковчега:** Арон (корень ב.ר.כ) → Каппорет (преклонение колена → передача силы) → Керувы (благословение — это передача способности).
- **Разбор:** браха — не «хорошее пожелание». Это наделение силой. Колено преклоняется — передаётся сила. Конкретное действие. Яхве благословляет — даёт способность. Отец благословляет сына — передаёт власть и наследие. Система сделала из этого «доброе слово».
- **Стихи:** Берешит 27:27 («Иаков получил браха от отца»).
- **Пример восстановления:** «И наделил их силой Всесильный» вместо «и благословил их Бог».
- **Оставшиеся варианты:** «наделение силой», «дарование способности».


### 5. БОГ / ГОСПОДЬ

- **Слово в переводе:** Бог / Господь
- **Ивритский оригинал:** אֱלֹהִים (Элоhим) / יְהוָה (Яхве)
- **Палео-образы Элоhим (справа налево):** א (сила/бык) + ל (посох/направление) + ה (окно/откровение) + י (рука/действие) + ם (вода/поток)
- **Палео-механика Элоhим:** א (сила) направляется ל (посохом) через ה (окно), приводится в действие י (рукой) и течёт в ם (поток).
- **Визуальная сборка Элоhим:** сила, направляющая дыхание через руку в поток.
- **Палео-образы Яхве (справа налево):** י (рука/действие) + ה (окно/дыхание) + ו (крюк/связь) + ה (окно/дыхание)
- **Палео-механика Яхве:** י (рука) связывает ה (дыхание) через ו (крюк) с ה (дыханием).
- **Визуальная сборка Яхве:** рука, связывающая дыхание с дыханием.
- **Функция Элоhим:** полнота сил.
- **Функция Яхве:** алгоритм, связывающий действие и проявление.
- **Корни:** א.ל.ה — быть сильным; ה.י.ה — быть, существовать, становиться.
- **`root_ref`:** `roots.json#elohim` (Элоhим), `roots.json#yhwh` (Яхве)
- **Живой образ Элоhим:** несколько сил, работающих вместе.
- **Живой образ Яхве:** конструкция, которая соединяет действие и проявление.
- **Тип искажения:** Подмена имени на титул + Сужение смысла.
- **Механизм подмены:** Религиозный синкретизм (Механизм 6) + Подмена палео-механики на греческую физику (Механизм 7).
- **Метод разоблачения:** Разрыв цепочки перевода + Морфологическое вскрытие.
- **Карта утрат:** Элоhим/Яхве → θεός (божество) → Deus (римский бог) → «Бог»/«Господь» (титул).
- **Уровень уверенности:** `факт` (имена зафиксированы в тексте).
- **Терминологическая проверка:** Элоhим — полнота сил. Яхве — личное имя, означающее «Тот, Кто был, есть и будет».
- **Хук Свива:** «Господь» создаёт среду Мицраим (тесноту) — ты не можешь обратиться по имени. Яхве создаёт среду Шамаим (открытость) — ты призываешь Его лично.
- **Принцип Ковчега:** Арон (корни א.ל.ה и ה.י.ה) → Каппорет (Элоhим как полнота сил, Яхве как алгоритм бытия) → Керувы (не переводить, оставлять имена).
- **Разбор:** Элоhим — форма множественного числа. Множественное величия. Полнота сил. В палео-иврите: бык (сила) + посох (власть) + дыхание (откровение) + рука (действие) + вода (жизнь). Яхве — личное имя, которое означает «Тот, Кто был, есть и будет» (алгоритм бытия). Система заменила имя и силу на греческий θεός (божество) и латинский Dominus (господин). Слово «Бог» — славянское, языческий корень, означает «наделяющий долей», связано с пантеоном.
- **Стихи:** Берешит 1:1 («Элоhим»), Шмот 3:14 («Яхве»).
- **Пример восстановления:** оставить «Элоhим» и «Яхве» без перевода. В крайнем случае — «Всесильный» и «Сущий».
- **Оставшиеся варианты:** «Всесильный» (для Элоhим), «Сущий» (для Яхве).


### 6. ВЕРА

- **Слово в переводе:** Вера
- **Ивритский оригинал:** אֱמוּנָה (эмуна)
- **Палео-образы (справа налево):** א (сила/бык) + מ (вода/поток) + ו (крюк/связь) + נ (жизнь/движение) + ה (окно/откровение)
- **Палео-механика:** א (сила) течёт через מ (поток), связывается ו (крюком) с נ (жизнью) и проходит через ה (окно).
- **Визуальная сборка:** сила, текущая жизнью, соединённая с живым, в откровении.
- **Функция:** твёрдость, надёжность, верность в действии.
- **Корень:** א.מ.נ — быть твёрдым, надёжным, верным.
- **`root_ref`:** `roots.json#emunah`
- **Живой образ:** человек, который стоит твёрдо и не шатается.
- **Тип искажения:** Психологизация + Сдвиг от действия к эмоции.
- **Механизм подмены:** Подмена многомерной истины плоским суррогатом (Механизм 3).
- **Метод разоблачения:** Этимологическая хирургия + Семантическая реконструкция.
- **Карта утрат:** эмуна (твёрдость) → πίστις (доверие) → «вера» (мнение) → «убеждение» (чувство).
- **Уровень уверенности:** `факт` (корень зафиксирован).
- **Терминологическая проверка:** эмуна — это верность, а не мнение.
- **Хук Свива:** «Вера» как внутреннее чувство создаёт среду Мицраим (тесноту) — ты можешь «верить» и ничего не делать. Эмуна как твёрдость создаёт среду Шамаим (открытость) — ты действуешь.
- **Принцип Ковчега:** Арон (корень א.מ.נ) → Каппорет (твёрдость как действие) → Керувы (верность — это стоять твёрдо).
- **Разбор:** эмуна — не «вера» как мнение. Это верность. Твёрдость. Надёжность. От корня амен — быть прочным. Эмуна — это когда ты стоишь твёрдо, держишь слово, не шатаешься. Система заменила действие на чувство: «верить» можно лёжа на диване. «Быть верным» — нельзя.
- **Стихи:** Берешит 15:6 («он был твёрд в Яхве»).
- **Пример восстановления:** «Праведный своей верностью жив будет» вместо «верою жив будет».
- **Оставшиеся варианты:** «верность», «твёрдость».


### 7. ВЕЧНОСТЬ

- **Слово в переводе:** Вечность
- **Ивритский оригинал:** עוֹלָם (олам)
- **Палео-образы (справа налево):** ע (глаз/источник) + ו (крюк/связь) + ל (посох/направление) + ם (вода/поток)
- **Палео-механика:** ע (глаз) видит ו (крюк), который направляет ל (посохом) в ם (поток) к скрытому.

- **Механизм подмены:** Подмена многомерной истины плоским суррогатом (Механизм 3) + Подмена живого отношения на мёртвую структуру (Механизм 4).
- **Метод разоблачения:** Палео-механический разбор (Метод 1) + Этимологическая хирургия.
- **Карта утрат:** хок (черта) → νόμος (закон) → lex (римский закон) → «закон» (кодекс).
- **Уровень уверенности:** `факт` (корень зафиксирован).
- **Терминологическая проверка:** хок — это черта, а не закон.
- **Хук Свива:** «Закон» как кодекс создаёт среду Мицраим (тесноту) — ты должен соблюдать. Хок как черта создаёт среду Шамаим (открытость) — поток течёт в русле.

- **Оставшиеся варианты:** «русло», «граница».


### 31. ЦЕРКОВЬ

### 32. ЧИСТЫЙ / НЕЧИСТЫЙ

- **Слово в переводе:** Чистый / Нечистый
- **Ивритский оригинал (таhор):** טָהוֹר (таhор)
- **Ивритский оригинал (тамэ):** טָמֵא (тамэ)
- **Палео-образы таhор (справа налево):** ט (змея/оборачивание) + ה (окно/откровение) + ר (голова/вершина)
- **Палео-механика таhор:** ט (змея) оборачивает ה (окно) к ר (вершине) — змея оборачивает дыхание к вершине.
- **Визуальная сборка таhор:** змея, оборачивающая дыхание к вершине.
- **Палео-образы тамэ (справа налево):** ט (змея/оборачивание) + מ (вода/поток) + א (сила/бык)
- **Палео-механика тамэ:** ט (змея) оборачивает מ (поток) вокруг א (силы) — змея оборачивает поток силой.
- **Визуальная сборка тамэ:** змея, оборачивающая поток силой.
- **Функция таhор:** пригодность.
- **Функция тамэ:** непригодность.
- **Корни:** ט.ה.ר — быть чистым, светлым; ט.מ.א — быть нечистым, непригодным.
- **`root_ref`:** `roots.json#tahor`, `roots.json#tamei`
- **Живой образ таhор:** человек, готовый войти в пространство.
- **Живой образ тамэ:** человек, который не готов войти.
- **Тип искажения:** Психологизация + Сужение смысла.
- **Механизм подмены:** Затуманивание ясного различия (Механизм 1).
- **Метод разоблачения:** Функциональное опознание + Семантическая реконструкция.
- **Карта утрат:** таhор/тамэ (пригодность/непригодность) → ἅγιος/ἀκάθαρτος (чистый/нечистый) → «чистый»/«нечистый» (мораль).
- **Уровень уверенности:** `факт` (корни зафиксированы).
- **Терминологическая проверка:** таhор и тамэ — это пригодность и непригодность, а не мораль.
- **Хук Свива:** «Чистый» как мораль создаёт среду Мицраим (тесноту) — тебя судят. Таhор как пригодность создаёт среду Шамаим (открытость) — ты либо готов войти, либо нет.
- **Принцип Ковчега:** Арон (корни ט.ה.ר и ט.מ.א) → Каппорет (пригодность как состояние) → Керувы (таhор/тамэ — это состояние, а не качество).
- **Разбор:** таhор и тамэ — не моральные категории. Это функциональные состояния. Таhор — пригоден для входа в присутствие Яхве. Тамэ — непригоден. Не «плохой» и «хороший». А «готов» и «не готов». Это ритуальный статус, а не оценка личности.
- **Стихи:** Вайикра 11:24 («тамэ до вечера»), Вайикра 14:4 («очищение таhор»).
- **Пример восстановления:** «пригодный» и «непригодный» вместо «чистый» и «нечистый».
- **Оставшиеся варианты:** «готовый/неготовый», «пригодный/непригодный».


### 33. ШЕОЛ

- **Слово в переводе:** Ад
- **Ивритский оригинал:** שְׁאוֹל (шеол)
- **Палео-образы (справа налево):** ש (огонь/зуб) + א (сила/бык) + ו (крюк/связь) + ל (посох/направление)
- **Палео-механика:** ש (огонь) направляется א (силой) через ו (крюк) к ל (посоху) — огонь, который сила направляет через связь к направлению.

- **Функция:** могила, место мёртвых.
- **Корень:** ש.א.ל — спрашивать, просить, требовать.
- **`root_ref`:** `roots.json#sheol`
- **Живой образ:** могила, которая принимает всех.
- **Тип искажения:** Вавилонизация + Дуализация.

- **Метод разоблачения:** Семантическая реконструкция + Сравнительная семитология.
- **Карта утрат:** шеол (могила) → ᾅδης (гадес) → infernum (ад) → «ад» (место мучений).

- **Стихи:** Берешит 37:35 («сойду в шеол»), Псалом 88:4 («душа моя полна шеол»).
- **Пример восстановления:** «могила» или оставить «шеол» без перевода.
- **Оставшиеся варианты:** «могила», «шеол».


### 34. МИЦРАИМ (מצרים)

- **Карта утрат:** Мицраим (искусственный канал) → Αἴγυπτος (Египет) → «Египет» (страна) → «Египет» (география).

- **Разбор:** Мицраим — это не страна. Это конструкция, которая выхватывает живое из естественного потока и перенаправляет его в искусственное русло. Человек в Мицраиме — это рыба в искусственном канале. Он движется, но не свободно. Его движение контролируется системой.

- **Пример восстановления:** «Выход из искусственного канала» вместо «Исход из Египта».

### 36. ШЕКЕР (שקר)

- **Слово в переводе:** Ложь
- **Ивритский оригинал:** שֶׁקֶר (Шекер)
- **Палео-образы (справа налево):** ש (огонь/зуб/разрушение) + ק (игла/отделённость) + ר (голова/направление)
- **Палео-механика:** ש (огонь) пронзает ק (иглой) и сдвигает ר (голову) — направление пронзено и сдвинуто.
- **Визуальная сборка:** направление, пронзённое и сдвинутое.
- **Функция:** искажение, перенаправление.
- **Корень:** ש.ק.ר — быть ложным, искажённым.
- **`root_ref`:** `roots.json#sheker`
- **Живой образ:** рыба, которую выловили крюком из естественного потока и бросили в искусственный пруд. Направление изменено.
- **Тип искажения:** Абстракция + Сужение смысла.
- **Механизм подмены:** Затуманивание ясного различия (Механизм 1) + Религиозный синкретизм (Механизм 6).
- **Метод разоблачения:** Этимологическая хирургия + Метод живого образа (Метод 36).
- **Карта утрат:** шекер (искажение) → ψεῦδος (ложь) → «ложь» (обман) → «фальшь» (мораль).
- **Уровень уверенности:** `факт` (корень зафиксирован).
- **Терминологическая проверка:** шекер — это искажение, а не ложь.
- **Хук Свива:** «Ложь» как моральный проступок создаёт среду Мицраим (тесноту) — тебя осуждают. Шекер как искажение создаёт среду Мидбар (поиск) — ты смотришь, куда сдвинулось направление.
- **Принцип Ковчега:** Арон (корень ש.ק.ר) → Каппорет (искажение как сдвиг) → Керувы (шекер — это когда конструкция сдвигается из правильного русла).
- **Разбор:** Шекер — это не «ложь» в моральном смысле. Это **перенаправление конструкции** из естественного русла в искусственный канал. Конструкция сдвигается, направление меняется. Это когда что-то сдвигается с правильного русла (Реш) через внешнее вмешательство (Шин + Коф).
- **Противоположность:** Эмет (אמת) — конструкция в правильном русле.
- **Пример восстановления:** «Это не шекер» — «Это не искажение» вместо «Это не ложь».
- **Оставшиеся варианты:** «искажение», «сдвиг».
