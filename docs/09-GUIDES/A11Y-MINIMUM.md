# Минимальная доступность Research Lab и лендинга

- **Файл:** `docs/09-GUIDES/A11Y-MINIMUM.md`
- **Статус:** Активный
- **Опора:** `docs/10-DESIGN/DESIGN-SYSTEM.md`
- **Связанные:** `docs/09-GUIDES/ERROR-HANDLING.md`, `docs/08-AUDITS/WEBSITE-AUDIT.md`

## Зачем

Минимум, ниже которого UI-изменение не принимается. Это не полный аудит WCAG,
а правила против четырёх классов дефектов, которые в проекте уже случались:
недоступная клавиатура, цвет как единственный носитель смысла, немые статусы
загрузки и ошибок, иврит без направления.

Источник требований — `docs/10-DESIGN/DESIGN-SYSTEM.md` (разделы 0.2 «Правила-законы»
и 1.1 «Цветовые роли»). Здесь — операционный чек-лист.

## Обязательный минимум

### 1. Семантика

- Один `<main>` на страницу: лаборатория — `#labContent` (`apps/researchlab/index.html`),
  лендинг — `#main-content` (`products/website/index.html`).
- Интерактив — `<button>` или `<a>`, не `div[onclick]`. Кнопка без видимого текста
  получает `aria-label`.
- Заголовки по уровням без пропусков; смысловые блоки — `<section aria-labelledby>`
  (пример: `apps/researchlab/pages/timescale-generator.html`).
- Декоративные иконки и глифы — `aria-hidden="true"`; смысл глифа дублируется текстом.

### 2. Клавиатура и фокус

- Всё, что доступно мышью, доступно с клавиатуры; Tab-порядок совпадает с визуальным.
- Видимый фокус обязателен (`:focus-visible`); `outline: none` без видимого заменителя запрещён.
- Модалки и оверлеи: `Escape` закрывает, фокус входит внутрь и возвращается на триггер.
- `skip-link` нужен на каждой странице с шапкой и сайдбаром. Лендинг его имеет
  (`.skip-link` → `#main-content`); у лаборатории **skip-link пока нет** — добавить
  вместе с ближайшей правкой шапки, а не отдельным рефактором.

### 3. Текст и цвет

- Статус, уверенность, эмет/шекер — всегда словом или иконкой; цвет не единственный носитель смысла.
- Акцентный **текст** — `--gold-text` / `--red-text` (≥4.5:1 во всех темах);
  `--accent-gold` — для линий и заливок.
- Вторичный текст на светлых панелях — `--text-secondary`: `--text-muted` в темах
  light/white/beige не добирает AA.
- Иврит: `lang="he"` + `dir="rtl"`; палео-глифы — `lang="hbo"` (канон: `js/scripture-reader.js`).
- Touch-target ≥ 44×44 px для кнопок на мобильных.

### 4. Динамика и объявления

- Статусы — `role="status" aria-live="polite"` (канон: `class="lab-status"`), ошибки — `role="alert"`.
- Переход по маршруту не «телепортирует» пользователя: фокус остаётся в осмысленном месте.
- При `prefers-reduced-motion: reduce` анимации выключаются, движение заменяется появлением.
- Спиннер — не состояние: вечный спиннер считается ошибкой (см. `docs/09-GUIDES/ERROR-HANDLING.md`).

## Как проверять

1. Обход клавиатурой: `Tab` / `Shift+Tab`, `Escape` на оверлеях — фокус виден, ловушек нет.
2. Маршруты: `cd products/website/apps/researchlab && npm run test:smoke` — консоль, mobile overflow, спиннеры.
3. Контраст: DevTools → Inspect → Contrast Ratio по паре «фон из токена / текст из токена».
4. Автоматического a11y-гейта в CI **нет** (Lighthouse/axe не подключены). Массовая правка
   разметки проверяется по этому списку вручную — это осознанное ограничение, а не забытый шаг.

## Запрещено

- `div[onclick]` вместо кнопки; `outline: none` без заменителя.
- Цвет как единственное различие статусов и уровней уверенности.
- Ошибка без действия и без объявления (см. `docs/09-GUIDES/ERROR-HANDLING.md`).
- Новое правило «на будущее» без правки этого файла: сначала пункт, потом код.
