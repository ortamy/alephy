# Бюджеты производительности

- **Файл:** `docs/09-GUIDES/PERFORMANCE.md`
- **Статус:** Активный
- **Опора:** `docs/01-ARCHITECTURE/ARCHITECTURE.md`
- **Связанные:** `docs/09-GUIDES/ERROR-HANDLING.md`, `docs/08-AUDITS/WEBSITE-AUDIT.md`, `docs/decisions.md`

## Зачем

Лаборатория — тяжёлое SPA на десятках модулей и JSON-данных. Бюджет нужен, чтобы
каждая следующая фича не превращала первый заход в ожидание. Ниже — числа, ниже
которых правка не принимается, и то, что уже сделано в коде ради этих чисел.

## Бюджеты

| Метрика | Порог | Область |
|---|---|---|
| Бандл лаборатории без данных | < 200 KB gzip | `apps/researchlab/js` + `css` |
| Одна страница (JS + CSS) | < 50 KB gzip | документ + его модуль |
| LCP | < 2.5 с | лаборатория и лендинг |
| Изображения ниже сгиба | lazy-load | предпочтительно SVG/WebP |
| Шрифты | subset + preload | только критичные начертания |
| Новая зависимость | > 20 KB gzip → ADR | `docs/decisions.md` |

## Что уже сделано (не ломать)

- **Шрифты неблокирующие.** В `apps/researchlab/index.html` и `products/website/index.html`
  Google Fonts подключаются как `rel="preload" as="style"` + `onload` → `stylesheet`,
  с `<noscript>`-дублем. Причина в комментарии разметки: блокирующий fetch к CDN
  при недоступной сети вешал первую отрисовку на 10–20 секунд. Возврат к
  блокирующему `<link rel="stylesheet">` на внешний домен — регресс.
- **Нет внешних CDN-скриптов.** `marked` держится локально (`js/libs/marked.min.js`);
  внешний CDN уже один раз фризил парсер до таймаута соединения
  (см. `tools/design-baseline/README.md`).
- **Данные — отдельными JSON** с локальным fallback (`js/lab-search.js`), а не
  инлайном в HTML: словари не читаются на каждой загрузке страницы.
- **`sw.js` (v27):** навигация — network-first, статика — stale-while-revalidate.
  Первый заход не ждёт прогрева длинного precache-списка.

## Как измерять

1. **Вес.** Сырой размер модулей:
   ```powershell
   Get-ChildItem js, css -Recurse -File | Measure-Object Length -Sum
   ```
   gzip-размер смотреть в DevTools → Network с включённым «Disable cache»: столбец
   Transfer size, а не Resource size.
2. **LCP.** Lighthouse в чистом профиле. Перед замером снять Service Worker
   (DevTools → Application → Service Workers → Unregister) и обновить страницу:
   иначе SW отдаёт кэш и метрика занижается.
3. **Идентичность окружения.** Сравнения «до/после» делать в одном профиле, одной
   ширине окна и одной теме: цифры без этого несопоставимы.

## Правила при правке

- Новый модуль инициализируется при заходе на маршрут (реестр + `page-controller`),
  а не на старте приложения.
- Тяжёлые вычисления — по действию пользователя, а не в обработчике маршрута.
- Изображения: `loading="lazy"` ниже сгиба, SVG для иконок и глифов, WebP для фото.
- Новая библиотека > 20 KB gzip — сначала ADR в `docs/decisions.md`, потом код.
- Правка кэшируемых файлов требует подъёма `CACHE_NAME` в `sw.js`: иначе пользователь
  получает старый файл и «баг не воспроизводится» на его машине.

## Открытые пункты

- Автоматического перф-гейта нет: бюджет проверяется вручную, CI следит только за
  регрессиями маршрутов (smoke) и паритетом build.
- Числа бюджета пока не зафиксированы замером. Первый срез (дата, маршрут, браузер,
  LCP, gzip) стоит положить в `docs/08-AUDITS/` — тогда отклонение станет видимым.

## Запрещено

- Блокирующие внешние шрифты и скрипты в `<head>`.
- Новые зависимости без ADR.
- Инлайн больших JSON/словарей в HTML или JS.
- Оптимизация «по ощущениям» без замера до и после.
